## 📌 Project Overview
A hands-on repository dedicated to **Exploratory Data Analysis (EDA)**, statistical exploration, data visualization, and quality validation using Python. The notebooks explore academic and behavioral indicators influencing student performance.

---

## 📁 Repository Contents
- **`EDA_sample_dataset.ipynb`**: Complete step-by-step walkthrough of EDA fundamentals, data inspection, and distribution plots.
- **`Student_Dataset_Analysis.ipynb`**: Detailed student dataset evaluation covering demographic variables, study hours, and academic marks.
- **`eda_sample_dataset.csv`**: Sample tabular dataset used for data wrangling exercises.
- **`student_marks.csv`**: Structured student exam scores, attendance, and study habits dataset.

---

## 🔎 EDA Steps Performed
1. **Initial Assessment**: Inspecting data shape, datatypes (`.info()`), missing values (`.isnull().sum()`), and descriptive statistics (`.describe()`).
2. **Univariate Analysis**: Histograms, KDE plots, and box plots to observe single-variable distributions and detect outliers.
3. **Bivariate & Multivariate Analysis**: Scatter plots, pair plots, and correlation heatmaps to identify relationships between study hours, attendance, and marks.
4. **Data Cleaning**: Imputing null values and correcting anomalous records.
